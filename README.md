### Quick Actions

* **[Read the Visual Beginner Guide (PDF)](./guides/GitHub-Beginner-Guide.pdf)** — Step by step visual walkthrough from creating an account with Google to merging your first Pull Request.
* **[Submit a Project or Tutorial Repo](../../issues/new?template=1-submit-project.yml)** — Add your repository to the live community directory below.
* **[Ask for Help on Code, Bugs, or Docs](../../issues/new?template=2-ask-for-help.yml)** — Broadcast a specific blocker so peers and seniors can send a Pull Request.
* **[Request a Senior Code Review](../../issues/new?template=3-request-code-review.yml)** — Request an architecture or code quality check from experienced peers and alumni.
* **[Download Audited Final Year Project Report Reference (DOCX and PDF)](https://github.com/MSEC-Code-Club-Zero/project-report-reference)** — Department audited formatting template for final year documentation.
